# R+MUNI QuickStart

`Cost: 0 | Color: Weiß | Type: EUMAXL — QuickStart | Season: S01`

---

## Willkommen im R+MUNI Universum

R+MUNI ist kein Regelwerk das du auswendig lernen musst.
Es ist ein Denkmodell — eine Arbeitslinse die du sofort verwenden kannst.

Du bringst dein Projekt mit. R+MUNI gibt dir die Struktur.
Was du daraus machst ist dein Spiel.

---

## Was du brauchst um loszulegen

**Drei Dinge:**

1. **Ein Thema** — Was beschäftigt dich gerade? Ein Verein, ein Projekt, ein Problem?
2. **Eine KI** — Claude, ChatGPT, Copilot. Egal welche — das Prinzip funktioniert mit allen.
3. **MGT00** — Die Startkarte. Gibt sie der KI. Warte auf READY. Los geht's.

Das ist alles. Keine Vorbereitung. Kein Regelwerk zuerst.

---

## Das Spielfeld

R+MUNI organisiert alles in **Zonen** — angelehnt an Magic: The Gathering.
Jede Zone hat eine Bedeutung:

| Zone | Ordner | Was liegt dort |
|---|---|---|
| **General** | 00-General | Dein Setup — Prompt, Methode, QuickStart |
| **Library** | 01-Library | Deine Prinzipien — was du ziehen kannst |
| **Hand** | 02-Hand | Dein aktiver Kontext — was du gerade hältst |
| **Battlefield** | 03-Battlefield | Was im Spiel ist — aktiv laufende Dinge |
| **Graveyard** | 04-Graveyard | Backlog — erledigt aber jederzeit abrufbar |
| **Stack** | 05-Stack | Was gerade gespielt wird — aktive Sprints |
| **Exile** | 06-Exile | Stage-abgeschlossen — aus dem Spiel aber nicht vergessen |

Du musst die Zonen nicht sofort befüllen.
Spiel zuerst — die Struktur entsteht von selbst.

---

## Wie ein Zug aussieht

Ein typischer R+MUNI Zug folgt dem Session-Prinzip:

```
Untap   → Kontext herstellen — was liegt auf dem Tisch?
Upkeep  → Was läuft noch aus dem letzten Zug?
Draw    → Was ziehst du heute — welche Karte spielst du?

Main    → Freie Beschreibung deines Themas — erzähl einfach
Combat  → Trigger "du bist" — die KI strukturiert und gibt Form
End     → Output bestätigen — Karte landet in der richtigen Zone
```

**Mana-Check vor jedem neuen Zug:**
1. Haben wir noch Bock?
2. Können wir uns das leisten?
3. Wer macht's?

Wenn alle drei ✅ → Karte spielen.
Wenn eine ❌ → Karte bleibt auf der Hand.

## Karten — was sie sind und wie sie aussehen

Jedes Dokument in R+MUNI ist eine Karte.
Jede Karte hat dieselbe Anatomie:

```
# Kartenname

Cost: <Mana>  |  Color: <Kategorie>  |  Type: <Bearbeiter — Dokumententyp>  |  Season: <S00>

Textbox:
  Situation → was war der Auslöser
  Action    → was wurde getan
  Effect    → was hat es bewirkt
  Insight   → was bleibt als Erkenntnis
  Combo     → mit welchen anderen Karten wirkt sie zusammen

Damage: <Auswirkung>  |  Life: <Stabilität>
```

**Was die Felder bedeuten:**

| Feld | Bedeutung |
|---|---|
| **Cost / Mana** | Aufwandsschätzung — wie viel kostet diese Karte? |
| **Color** | Kategorie oder Weg — z.B. Infrastruktur, Kommunikation, Natur |
| **Type** | Wer bearbeitet es — und welcher Dokumententyp ist es (Sprint, Backlog, Notiz…) |
| **Season** | Aktueller Stage — S00, S01, S02… |
| **Damage** | Auswirkung — was verändert diese Karte im System? |
| **Life** | Stabilität — wie stabil ist das System danach? |

## Deine erste Runde — unter 60 Minuten

**Schritt 1** — MGT00 öffnen, Inhalt in neue KI-Session einfügen. Auf READY warten.

**Schritt 2** — Frei erzählen: "Ich hab einen Verein / ein Projekt / ein Problem…"

**Schritt 3** — Trigger "du bist" wenn du Struktur willst.

**Schritt 4** — Output als Karte in die richtige Zone legen.

**Schritt 5** — Mana-Check. Nächste Karte oder Session beenden.

Fertig. Du hast gespielt.

## Glossar — die R+MUNI Sprache

| Begriff | Bedeutung in R+MUNI |
|---|---|
| **Deck** | Dein gesamtes Projekt — alles was dazu gehört |
| **Karte** | Ein Dokument, eine Entscheidung, ein Vorhaben |
| **Mana** | Ressourcen — Zeit, Geld, Manpower |
| **Land** | Wer oder was Mana liefert — Personen, Budgets, Infrastruktur |
| **Hand** | Was du gerade aktiv hältst — dein aktueller Kontext |
| **Zug** | Eine konkrete Maßnahme oder Session |
| **Combo** | Wenn mehrere Karten zusammenspielen und mehr bewirken als einzeln |
| **Schlummer** | Karten die existieren aber bewusst nicht gespielt werden |
| **Graveyard** | Backlog — erledigt aber abrufbar |
| **Stack** | Aktiver Sprint — was gerade in Bearbeitung ist |
| **Exile** | Stage-abgeschlossen — nicht mehr aktiv |
| **Saison / Season** | Stage der Entwicklung — S00 ist der Anfang |
| **Selektion** | Wer passt ins Deck — DNA-Check vor jedem neuen Mitspieler |
| **Horizont** | Wie lange läuft das Spiel — wann kommt die Exit-Bedingung? |

---

## Was R+MUNI nicht ist

- Kein Ersatz für Entscheidungen — die trifft immer der Mensch
- Kein Zwang zur Vollständigkeit — spiel was du spielen kannst
- Kein Regelwerk das du auswendig kennen musst
- Kein Produkt das du kaufen kannst — es entsteht durch Spielen
