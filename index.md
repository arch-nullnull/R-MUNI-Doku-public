# 🧠 R+MUNI Grundprinzipien

**1. Offenheit**  
R+MUNI zeigt, wie es gebaut wird. Keine Blackbox.

**2. Ehrlichkeit**  
Keine Versprechen, keine Verkaufslogik, keine versteckten Ziele.

**3. Reproduzierbarkeit**  
Jeder Schritt ist dokumentiert, nachvollziehbar und wiederholbar.

**4. Tool Agnostik**  
R+MUNI zwingt niemanden in ein Ökosystem. Es bietet aber eines an! 

**5. Governance**  
Jede Änderung folgt klaren Regeln (GOV 10.x).  
Nichts passiert implizit.
